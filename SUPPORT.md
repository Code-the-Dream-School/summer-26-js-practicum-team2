# Support

## Getting Help

Use this guide to choose the right place for questions, bugs, and security concerns.

## Where to Ask

- Questions and usage help: open a GitHub Discussion (preferred) or ask in your team communication channel.
- Bugs and regressions: open a GitHub Issue and include reproduction steps.
- Feature ideas: open a GitHub Issue using the feature request template.
- Security vulnerabilities: do not open a public issue. Follow the private reporting process in `.github/SECURITY.md`.

## Before You Open an Issue

- Search existing issues first.
- Include clear steps to reproduce.
- Include environment details (OS, browser, Node version, branch).
- Include logs, screenshots, or request/response examples when relevant.

## Response Expectations

This is a practicum project maintained by contributors and mentors. Response times can vary, but maintainers will triage new issues as availability allows.
